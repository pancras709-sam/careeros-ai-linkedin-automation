# CareerOS AI Student

CareerOS AI Student is an AI-powered career platform designed to help students manage different parts of their career journey in one place.

The idea came from a simple problem: students often use different websites for finding jobs, researching companies, preparing for coding contests, planning their careers, and getting career guidance. CareerOS brings these activities together into a single platform.

## What Does It Do?

CareerOS is designed to help students:

* Explore career and job opportunities
* Discover and compare companies
* Get AI-powered career guidance
* Build and follow a career roadmap
* Find coding contests and technical opportunities
* Get career-related recommendations
* View student and college-related insights
* Manage different career activities from one dashboard

## AI Features

The application uses Google Gemini to provide AI-powered functionality.

The AI features are designed to support:

* Career guidance
* Personalized suggestions
* Career planning
* Opportunity-related assistance
* Student-focused interactions

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

### 2. Open the project

```bash
cd YOUR_REPOSITORY_NAME
```

### 3. Install dependencies

Using Bun:

```bash
bun install
```

### 4. Configure environment variables

Create a `.env` file using `.env.example` as a reference.

Add the required Gemini API configuration.

For example:

```env
GEMINI_API_KEY=your_api_key_here
```

Do not upload your actual API keys or other private credentials to GitHub.

### 5. Start the development server

```bash
bun run dev
```

Open the local URL displayed in the terminal.
